Vision MOD Privacy Policy

Effective date: November 18, 2026

This policy applies to Vision MOD for macOS (Mac App Store) and Windows (Microsoft Store).

Data Collection

Vision MOD does not collect personal data. The app has no user accounts, no analytics, no advertising, no tracking and no crash reporting. It does not send camera images, audio, MIDI data, settings, recordings or any other content to MADZINE or to any server.

Network Activity

The only network activity of the app is the in-app purchase and restore flow, which is handled by Apple (App Store) on macOS and by Microsoft (Microsoft Store) on Windows. On macOS the app has no network access permission of its own.

Online Manual

The MANUAL button opens the user manual in your default web browser at an address of the form https://madzine.work/assets/manuals/visionmod/VisionMOD_Manual_<version>_<language>.html. The address contains the app version and the current interface language (en, ja or zh-Hant). This happens only when you press the button. The connection is made by your browser, not by Vision MOD, and Vision MOD adds no other data to it.

Camera, Microphone and MIDI

Vision MOD requests camera access to use the camera image as its visual source, and microphone or audio input access to use audio levels as modulation and to pass audio input through the built-in audio effects. MIDI Control Change messages from connected MIDI devices control app parameters. All of this is processed in real time on your computer and is not uploaded. Microphone and audio input are never recorded.

You can turn off camera and microphone access at any time: on macOS in System Settings > Privacy & Security > Camera / Microphone, on Windows in Settings > Privacy & security > Camera / Microphone.

Video Recording

When you use the record function, Vision MOD saves a video file of the output image, together with the sound of a video file you play as a source (if any), to the location you choose in the save dialog. Microphone and audio input are not included. Recordings are not uploaded and stay where you saved them.

AI Processing

Image generation (Stable Diffusion on macOS, Stream Diffusion on Windows) and the app's other AI processing run locally on your computer. No image is uploaded to any server.

Local Files

Vision MOD stores the following on your computer only. On the Mac App Store version, all of these locations are inside the app's sandbox container.

  • Settings and module state: .visionmod/app_state.json in your user folder. This file contains the names of the camera, audio and MIDI devices you selected and the file paths of media files you chose.
  • MIDI assignments: .visionmod/midi_mappings.json in your user folder.
  • Visual effect plug-ins: .visionmod/plugins/ in your user folder.
  • Color settings: .config/visionmod/hue.txt and .config/visionmod/saturation.txt in your user folder.
  • macOS only, in ~/Library/Application Support/VisionMod/: store_unlock.cache (records only that the purchase is active), sandbox_bookmarks.json (keeps access permission to files you selected) and instance.lock (prevents the app from opening twice).
  • Windows only: VisionMod\instance.lock in your local application data folder (prevents the app from opening twice).
  • Temporary files in the visionmod folder of the system temporary folder, used to pass camera and video frames and processing results between the app's own processes. They are emptied the next time the app starts.
  • Recordings and project files, only when you save them yourself, at the location you choose.

None of this data leaves your computer unless you copy or share it yourself.

Project Files

Project files you save or export contain the full file paths of the media files used in the project and the names of the selected devices. A file path can include your account folder name. Please keep this in mind before sharing a project file.

Third Parties

In-app purchases are handled by Apple on macOS and by Microsoft on Windows. Vision MOD only uses whether the purchase is active. Payment information is handled by Apple or Microsoft and is never available to MADZINE. Apart from this, Vision MOD shares no data with third parties, because it collects none.

User Control

Camera and microphone access can be revoked in the system settings listed above. Devices can be deselected inside the app at any time. To delete saved settings, MIDI assignments, plug-ins and color settings, delete the .visionmod and .config/visionmod folders in your user folder (on the Mac App Store version, inside the app's sandbox container).

Children's Privacy

Vision MOD does not collect personal data from anyone, including children under 13.
